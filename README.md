# SaaS Resume Builder Platform

A full-cycle SaaS platform designed to give users absolute control over their resume structure, styling, and layout through highly customizable templates. Built with a focus on robust backend architecture, scalable data storage, and automated billing.

## 🚀 Core Features
* **Customizable Template Engine:** A dynamic system allowing users to fully personalize their resume layouts and styles, ensuring pixel-perfect PDF rendering.
* **Payment Integration:** Secure, automated subscription handling and checkout using Stripe API and webhooks.
* **Cloud Storage:** Configured cloud object storage for robust management of user media and generated PDFs.
* **Admin Dashboard:** Custom admin panel for managing user tiers, generations, and platform settings.

## 🛠️ Tech Stack
* **Backend:** Python, Django, Django ORM
* **Database:** PostgreSQL
* **Infrastructure & Storage:** AWS S3 / Supabase
* **Monetization:** Stripe API
* **Deployment:** Render / Heroku

## ⚙️ Engineering Focus
The primary engineering challenge was building a scalable backend that supports complex, user-defined PDF template generation while maintaining a seamless and secure checkout pipeline for premium tiers.
